# ❤️ Heart Failure Prediction

A machine learning web app that predicts the risk of a heart failure death event based on patient clinical data.

## 🚀 Live Demo
> Deployed on Render — link available after deployment

## Live Link
https://heart-failure-prediction-6gxf.onrender.com/predict

## 🛠️ Tech Stack
- Python, Flask, Scikit-learn, Pandas
- Random Forest Classifier
- Deployed via Render

## 📋 Features
- Predicts heart failure risk from 12 clinical features
- English / Telugu language toggle
- Clean, responsive medical UI

## ▶️ Run Locally
```bash
pip install -r requirements.txt
python train_model.py
python app.py
```
